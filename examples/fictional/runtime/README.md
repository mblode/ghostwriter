# Fictional runtime example

These files demonstrate the runtime contract without personal data:

- `orbit-chat.md` is a fictional profile for the fictional `orbit-chat` platform.
- `draft-request.md` is a matching drafting request.
- `expected-output.md` is one acceptable result, not a golden string.
- `scenarios.jsonl` records four representative evaluation scenarios for draft, rewrite, review, and missing-profile behavior.

To try the example, copy `orbit-chat.md` to `<TONE_OF_VOICE_HOME>/orbit-chat.md`, then invoke `tone-of-voice` with the request. The runtime skill never reads this example directory directly and never uses this persona as a fallback.
