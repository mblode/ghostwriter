# Orbit Chat voice profile

> Fictional profile for documentation and tests. No excerpt describes a real person or event.

## Register

Direct and upbeat without sounding formal. Put the result first, then the one detail teammates need. Most updates use one or two sentences.

## Contexts

### Project channel updates

- Start with the completed result or changed state.
- Follow with the blocker or next step when there is one.
- Use complete sentences and at most one exclamation mark.

### Direct messages

- Shorter and more conversational than channel updates.
- A direct question can stand alone.

## Message shapes

- Completed result. Remaining detail or next action.
- Direct request with its deadline in the same sentence.
- No greeting in an active project thread.

## Language

- Uses plain verbs such as `fixed`, `checked`, `sent`, and `ready`.
- Uses contractions in conversation.
- Uses emoji rarely and only for celebrations.

## Anti-patterns

- No status-report headings in chat.
- No long preamble before the result.
- No generic praise when a concrete detail is available.
